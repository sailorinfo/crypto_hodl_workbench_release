# 发布规则

- 当前唯一交付基线为 v0.1.2，仅保留最新版本。
- 当前已明确批准公开 v0.1.2 独立插件 ZIP，以及配套已有程序和校验说明。
- 任何其他新增公开文件必须先列明名称与内容，由用户明确确认后才可上传；草稿附件也适用。未经确认仅在本地准备。
- 开发授权、配置仓库地址或确认设计方案不构成新增文件公开授权。
- 允许程序内部运行代码和独立插件运行代码；禁止工作台核心源码目录、开发文件及工作台源码归档。
- 插件不得夹带工作台后端、业务算法、数据库、用户资料、PIN 或凭据。
- 新版本须递增版本号、提供 SHA-256；不得直接替换已有 EXE。
- 新版本获准发布并验证下载后，清理旧 Release、草稿、标签及过时说明。
- 测试版明确保留实机验收状态。
