# 发布规则

- 当前唯一交付版本为 v0.1.4，仅保留最新版本。
- 本次获明确批准的公开附件为 Windows x64 便携 EXE、Apple 芯片 Mac ZIP 和配套 SHA-256 校验文件；不包含安装程序或浏览器扩展。
- 任何其他新增公开文件或附件必须先列明名称与内容，取得用户明确确认后才可上传；草稿附件也适用。
- 允许程序内部运行代码；禁止工作台核心源码目录、开发文件、用户资料及工作台源码归档。
- 新版本须递增版本号、提供 SHA-256；不得直接替换已有程序包。
- 新版本获准发布并验证下载后，清理旧 Release、草稿、标签及过时说明。
- 未完成的 Windows 实机验收和 Mac 未公证首次打开限制须在交付说明中明确。
