## 插件安装

解压插件 ZIP，打开 Chrome 扩展管理页，开启开发者模式并加载解压目录。ZIP 不是可直接双击安装的 CRX。先安装插件，再按侧栏引导安装桌面版，连接并在桌面解锁和授权。Windows Chrome 原生连接仍需实机验收。
